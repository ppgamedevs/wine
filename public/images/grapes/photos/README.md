They are not hotlinked. Each file was resized/converted to WebP; that modification
is noted here for CC BY-SA attribution.

`Rara Neagra` is treated here as the Moldovan/Romanian synonym of Babeasca
Neagra; the alt text states both names so the identification is transparent.

The application displays the author credit, license, and source link beside the
variety hero image. Downstream reuse must preserve attribution and share-alike
terms. No anonymous or unlicensed web images are used. When no attributable
species-specific photo was available, the original VinIntel illustration is kept
as a clearly labelled fallback.
