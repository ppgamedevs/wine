# Grape variety illustrations

These 640×640 transparent WebP illustrations are original VinIntel editorial
assets generated by `scripts/generate-grape-images.ts`. They are not stock
photos and require no third-party image licence.

The first curated set covers:

- Feteasca Neagra
- Feteasca Alba
- Feteasca Regala
- Tamaioasa Romaneasca
- Grasa de Cotnari
- Cramposie Selectionata
- Negru de Dragasani
- Novac
- Busuioaca de Bohotin
- Cadarca

Regenerate after changing the palette/illustration parameters:

```sh
npx tsx scripts/generate-grape-images.ts
```

The card uses `next/image` with fixed dimensions and a neutral icon fallback
when a guide has no image.
