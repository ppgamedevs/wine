# Grape variety images

Licensed Wikimedia Commons photos live in `photos/` with full attribution in
[`photos/README.md`](photos/README.md). The UI shows their credit, license and
source link and does **not** show the "Illustration" label.

This directory also contains 640×640 transparent WebP illustrations: original
VinIntel editorial assets generated by `scripts/generate-grape-images.ts`, based
on each variety's documented berry colour, cluster shape and relative berry
size. They are **representative artwork, not scientifically verified
photographs of the exact cultivars**. They are not stock photos and carry an
internal VinIntel licence (`© VinIntel`); no third-party image licence or
hotlink is involved. They are used only when no valid, attributable photo is
available and are labelled "Ilustrație / Illustration" (`imageKind:
illustration`).

The first curated set covers:

- Feteasca Neagra
- Feteasca Alba
- Feteasca Regala
- Tamaioasa Romaneasca
- Grasa de Cotnari
- Cramposie Selectionata
- Negru de Dragasani
- Novac
- Busuioaca de Bohotin
- Cadarca

Regenerate after changing the palette/illustration parameters:

```sh
npx tsx scripts/generate-grape-images.ts
```

The card uses `next/image` with fixed dimensions and a neutral icon fallback
when a guide has no image.
